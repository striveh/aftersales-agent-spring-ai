# 澄光数码退换货政策

本文是开源演示用的虚构店铺制度，不构成对任何真实商家的承诺。Agent 回答退换货问题时必须引用具体条款，不得凭印象放宽。

## 适用范围

澄光数码自营订单适用本政策。第三方卖家、企业集采合同、以及页面单独标注「不支持无理由退货」的预售商品，以订单页说明为准。下文日期均按北京时间的自然日计算。

## 签收时间的认定

签收时间以物流系统记录的签收日为准，不以用户口头描述的「上周」「最近」代替。签收当日计为第 0 天。自签收之日起满 7 个自然日仍可申请七天无理由，即签收日与申请日相距小于等于 7 天。没有签收记录的在途包裹，不适用七天无理由，走未签收拦截。

## 七天无理由退货

签收之日起 7 个自然日内，同时满足下面四条的，可以无理由退货：

1. 商品功能正常，没有质量故障声明。
2. 配件、赠品、说明书、保修卡齐全，不影响二次销售。
3. 无进水、摔坏、私自拆修等人为损坏。
4. 商品类目不在排除列表中。

耳机、音箱、键鼠、充电器等 3C 配件，拆封、试听、试戴不影响七天无理由，只要配件齐全且无人为损坏。退回运费由买家承担。符合本条时可以退回实付货款，但 Agent 不得直接打款。

## 不支持七天无理由的类目

下列商品不适用七天无理由退货：

- 定制商品，包括刻字、印名字、按买家尺寸制作的服饰。
- 食品、保健品、生鲜。另见「食品签收当日变质」。
- 贴身衣物、内衣、打底背心等拆封后影响二次销售的商品。
- 已激活的数字商品、会员、音视频充值、游戏点卡。未激活的数字商品，在签收之日起 7 日内、且账号未开通权益时，可以按七天无理由退货。

类目排除优先于「拆封不影响」的耳机例外。定制 T 恤即使只签收了两天，也不能走无理由退货。

## 食品签收当日变质

食品和生鲜不支持七天无理由。若在签收当日发现变质、发霉、漏液，可以退回实付货款。签收次日及以后不再按食品质量问题退款，请联系人工坐席个案处理。

## 十五天质量问题换货

耳机等电子类商品，签收之日起 15 个自然日内出现非人为的质量问题（无声、无法充电、异响、无法开机），优先换同款新机，不直接退款。换货运费由店铺承担。用户如果只是询问「能不能退」，但描述的是质量故障且仍在 15 日内，答复应为换货而不是退款。

## 配件缺失

七天无理由要求配件齐全。缺少充电线、耳塞、包装或赠品的，不能走无理由退货。质量问题换货不受本条限制：主机本身故障时，缺线仍可在十五天质量问题换货期限内换货。

## 退货运费

七天无理由退货的运费由买家承担。质量问题换货、物流丢件、物流破损、未签收拦截的运费或退回成本由店铺承担。食品签收当日变质的退回运费由店铺承担。

## 退款需要人工确认

退款、退差、补偿、退运费等任何资金动作，必须先生成待确认申请，由人工坐席或用户在对话里明确确认后才能入账。Agent 可以判断资格、起草原因和金额，但不得自动打款。用户只是询问「能退吗」时，只解释资格，不创建退款申请。用户明确说「帮我退款」「申请退款」且资格成立时，才创建待确认申请。已经退款的订单不能再次发起退款。
